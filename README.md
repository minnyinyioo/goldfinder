# 探金 Goldfinder

面向野外初学者的科学探金知识与记录工具。项目强调“迹象不等于矿体”，所有判断必须通过规范取样和实验室检测验证。

## 安全原则

- 遵守当地矿业、土地、环保与文物法规，并取得许可。
- 不公开敏感样点坐标，不提交密钥或个人记录。
- 不使用汞、氰化物等危险化学品进行个人提取。
- 本项目仅用于教育和记录，不构成投资、采矿或地质勘查结论。
